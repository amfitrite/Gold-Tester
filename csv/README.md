# CSV Datasets Directory

Folder ini digunakan untuk menempatkan file-file dataset CSV historis pasar Forex / Komoditas (seperti `xauusd_m1.csv`, `xauusd_m5.csv`, `xagusd_m5.csv`, dll.).

### Cara Penggunaan:
1. Tempatkan dataset CSV hasil download Dukascopy atau broker Anda ke dalam folder ini.
2. Aplikasi Desktop **Gold Tester** dan engine Python backtester akan secara otomatis mendeteksi dan memindai semua file CSV di folder ini.
3. Anda dapat langsung menjalankan simulasi dan backtesting melalui UI Desktop atau script command line.
